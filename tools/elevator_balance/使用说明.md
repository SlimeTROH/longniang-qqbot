# 无尽电梯数值工作台

启动后默认进入**首领赛季**。可按四个槽位搭配装备，调整地图强度、图鉴、虹彩背包技能和临装，分别计算单场胜率、清关撤离率与每次开局的净金。实测结果及条件见同目录的 **首领赛季数值报告.md**。在源码目录运行时直接加载当前游戏，独立压缩包内随附对应版本的规则快照。

右上角的**旧版对照**保留 2026 年 11 月 23 日 19:51 的历史版本。下方 A/B 说明和 **难度分析.html** 均用于重现该历史实验。

## 开始使用

Windows 双击 **启动工作台.cmd**，浏览器会打开本机工作台。保留启动窗口即可持续使用，按 Ctrl+C 可关闭服务。计算使用 Python 3.10 或更高版本及 NumPy。把工具包复制到新电脑时可执行：

~~~powershell
py -3 -m pip install numpy
py -3 app.py
~~~

## 调参

1. 在左侧选地图、参考玩家和要观察的楼层。A 始终读取固定快照。B 可选复制 A、连续属性软上限或建议的胜率校准方案。
2. 在 **单场战斗** 看普通怪、精英的击杀/阵亡/平局、平均回合、平均掉血、逃跑和单箱期望。默认满血，也能在配装页改为残血。
3. 在 **远征收益** 选清层或到层即撤、战斗或逃跑、保险、安全箱、咖啡、烟雾弹、通行证机会成本。点击模拟后，每一层都有到层率、撤离率、净变现分布和配对收益差。
4. 在 **装备与战力** 设置三个部位、品质、属性滚值、词条、套装与撤离成长。下方底材表可逐项修改 B。用 **反推装备底材** 可求已穿物品的单项属性达到目标胜率所需的最小增量。
5. 在 **胜率校准** 设普通怪与精英各自的首层、极限胜率和半程层数。点击生成后，B 使用提前算好的固定怪物分布。更换参考玩家会改变测算结果。**核验四图排序** 可检查同一玩家是否在更难的图反而有更高胜率。
6. 在 **地图参数** 可改金币门票、伏击、宝物估值、稀有率、怪物倍率、基础面板、事件权重、装备回收价与箱价。修改怪物属性公式会清除该图已拟合的概率模板。调整估值或箱价会保留这些模板。

**保存实验 JSON** 会保存方案、配装、策略、地图、样本数、楼层和随机种子。**导入实验或方案** 同时接受已保存的实验与 results 目录的建议方案。**导出候选代码 ZIP** 会生成可审阅的候选游戏文件、数值方案和原始源码校验值。成品装备已经入库的滚值与新底材是两种数据。正式采用方案时，知识库与游戏中手写的数值说明也需要与候选版本一致。

## 两个可复算的例子

- 地铁 F8，选择 **3 撤绿装** 和 **复制线上规则 A**。在装备页选撬棍、攻击、普通怪、目标 90%。从当前底材 9 增到 13 时击杀率约 89.78%，增到 14 约 93.76%。
- 商场，选择 **无装新人** 和 **建议 · 胜率校准**。普通怪首层胜率 99.95%，极限 72%，半程 12 层。F13 的满血参考胜率为 85.975%，F25 为 78.9875%。再切到远征页，可以看到残血连续作战后的撤离率。

命令行同样使用界面所用的计算入口：

~~~powershell
py -3 app.py --calculate 示例实验.json --out 计算结果.json
py -3 app.py --export results/建议方案.json --out 候选规则.zip
py -3 verify.py
py -3 study.py --workers 6 --n 6000
~~~

重建独立图文报告还需 Matplotlib，然后运行 **report.py**。主研究数据可由公开基准和固定种子重算。随包的玩家面板等权汇总来自当时线上快照，压缩包仅载入汇总表。

## 模型文件

| 文件 | 作用 |
|---|---|
| model.py | 面板、伤害分布、首达概率递推、源引擎采样、战力、胜率拟合与跨图检查 |
| voyages.py | 用源游戏 Turn 在内存 SQLite 中模拟逐层远征，分支核算撤离和变现 |
| economy.py | 按品质、物品、品相、回收价展开单次掉落和装备箱期望 |
| tuning_rules.py | 工作台和候选游戏共用的怪物属性及概率曲线 |
| app.py、index.html、app.js、style.css | 本机计算服务、CLI 和浏览器界面 |
| rules/ | 原规则快照和 SHA-256 清单 |
| study.py、verify.py、report.py、results/ | 批量计算、交叉验证、报告生成和 CSV 结果 |

## 读数

- 工具的战力是标准商场 F5 普通怪的 50% 击杀临界倍率相对无装新人的指数。敏捷先手、低血被动、经济词条和长期续航各有不同作用。
- 无反伤、无低血联动时，单场支持精确递推。带反甲刺猬或孤注一掷时，调用快照中的实际战斗函数抽样。反推底材与精确概率校准需采用可递推的参考玩家。
- 单场掉血测到战斗结束。整局额外结算吸血、咖啡、消耗护盾、安全箱、倒地替身和撤离伏击。
- 远征净变现按实际可售物资、钱包变化、入场和补给费用计量。默认安全箱自动保护高估值可锁物，自动用药时将咖啡和烟留在包内。社会救援、群友遗物、日限任务奖金与未来收藏价值可另列入经营目标。
- 不同目标层共享同一条主路径，误差计算以每次独立开局为单位。有限样本的最佳目标层是该套策略和目标下的估计。
- 候选方案将深层精英设为精英强档的 12%。它来自同一参考怪物家族，对四图依次要求毕业参考装阵亡率至少 45%／50%／55%／60%。该分支的出现概率也纳入入图参考玩家的胜率反推。设为 0 可以比较只有普通强档的方案。
